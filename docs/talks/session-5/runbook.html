The real split is agent TYPE:
• Service Agent → gets its own Einstein Agent user, non-login, own profile. Right for a public site where nobody is logged in.
• Employee Agent (Polly) → no user field exists. She borrows the asker’s.

“Agentforce gives you two kinds of agent. A Service Agent gets its own Einstein Agent user — this org has eleven already — and that is right for a public site, where nobody is logged in. That matters, because an agent with its own user queries as that user, not as the person asking, and that user is nearly always permissioned wider than they are. I did not remove a guardrail.
